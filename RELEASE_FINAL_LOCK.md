## Release gate
The feature requirements above are locked. However, an app is **not declared Play Store production-ready merely because requirements are locked**. Before publishing, the actual release artifact must pass build/signing checks, Firebase production configuration, Firestore/Functions security review, payment/payout provider integration, KYC/compliance requirements, privacy/data-safety disclosures, Play policy checks, and real-device testing. Any item that is not truly implemented must remain a release blocker rather than being represented as complete.

No feature, payment, payout, security control or compliance requirement may be silently downgraded to a demo/mock implementation. Changes require explicit owner approval.
