# Best Nikah Bridge — Locked Welcome Screen

This is the locked/final Welcome screen specification for the next production Android release.

## Visual source
Use the user-approved Welcome screen artwork supplied in the project conversation on 2026-09-01 as the exact visual reference. Do not replace it with a generic, AI-generated, stock, or demo welcome screen.

## Required elements
- Bismillah calligraphy at the top
- Welcome heading
- Best Nikah Bridge bridge/heart logo
- BEST NIKAH BRIDGE brand name
- Meaningful Matches
- Verified Profiles
- Private & Safe
- Urdu language selector
- Real Get Started button
- Real Sign In button
- English/Urdu labels matching the approved artwork

## Interaction requirements
- Get Started must open the real Firebase account/profile onboarding flow.
- Sign In must open the real Firebase authentication flow.
- Language selector must switch the actual app UI language.
- No button may be a visual-only/demo control.
- No seeded/demo member data may be displayed anywhere in production.

## Release rule
This screen is locked. Future production changes must preserve the approved layout/branding unless explicitly approved by the product owner.
