# Best Nikah Bridge — Daily Like & Profile Card Rules

**Status: FINAL / LOCKED**

## Main Marriage/Match screen
Each profile card should show the key information clearly, including:
- Profile photo
- Name
- Age
- Verification status/badge when verified
- Distance/location where privacy settings allow
- Country
- Profession/occupation
- Faith/practice information selected by the member
- Marriage intention/timeline
- Relevant compatibility/preference highlights

The screen should keep the clean, simple card interaction shown in the approved reference: profile information remains readable while the action buttons stay accessible.

## Daily likes
- Free/member daily allowance: **20 likes per calendar day**.
- A like consumes exactly 1 daily like.
- The counter must prevent more than 20 likes in the same calendar day.
- When the next calendar day begins, the allowance resets to **20** automatically.
- The reset must not require the user to reinstall, log out, or manually reset anything.
- Remaining likes should be visible to the member, e.g. `15 / 20 likes left today`.
- The daily limit applies to likes, not to profile viewing or browsing.
- Existing mutual/connection behavior remains unchanged: a mutual response can unlock the appropriate next-stage communication flow according to the app's safety rules.

## Important
Do not replace the 20-like daily rule with 5 unless the owner explicitly requests that change. The earlier 20 -> 5 idea is deferred; **20/day is the current final requirement**.
